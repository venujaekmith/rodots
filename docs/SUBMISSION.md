# Submission guidance

Submit the controller source and any files it needs to run. Include a short README with:

1. Your team and controller entry point.
2. The programming language and any dependencies.
3. How to build and run it in Webots R2025a.
4. Any command-line arguments or configuration needed before a trial.
5. A brief description of your line following, junction decisions, obstacle recovery, and checkpoint recognition.

Use relative paths for files shipped with your controller. Test from a clean extracted directory before submitting. Do not rely on a personal `D:\REIDBOTS` path, a private world file, or a locally installed library that is missing from your submission.

The official submission channel and deadline will be announced by the organizers.
